# Sales Data Analysis Using NumPy

## Project Overview
This project simulates one year of sales data for 10 stores across 12 months using Python and NumPy.

## Features
- Generate random monthly sales data.
- Reshape sales data into four quarters.
- Use NumPy arrays for data manipulation.
- Analyze sales across stores and months.

## Technologies Used
- Python
- NumPy
- Google Colab

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Run the cells in order.
3. View the generated sales data and array shapes.
